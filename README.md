## 📖 About the Project

The **Password Strength Checker** is a Python-based application that evaluates the strength of a password using standard cybersecurity guidelines.

It checks whether a password contains:

- ✅ Minimum 8 characters
- ✅ Uppercase letters
- ✅ Lowercase letters
- ✅ Numbers
- ✅ Special characters

Based on these checks, the application classifies the password as:

- 🔴 Weak
- 🟡 Medium
- 🟢 Strong

It also provides suggestions to help users create stronger and more secure passwords.

## ▶ Usage

1. Run the program.
2. Enter a password.
3. The application analyzes the password.
4. It displays the password strength.
5. If needed, suggestions are shown to improve password security.
